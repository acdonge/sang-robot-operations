# Official AAS schema dependency

`official/aas-3.1.2.schema.json` is the normative JSON Schema from
IDTA `IDTA-01001-3-1-2`, release tag `v3.1.2`, commit
`a93e41c07c4018e864cba6016b760b9c7e0d849f`.

The schema is licensed by the Industrial Digital Twin Association under
CC-BY-4.0. Its source, exact path, version, and SHA-256 are pinned in
`metamodel.lock.yaml`. SANG validates imported JSON against that unchanged
schema. SANG does not claim that its read-only projection implements the AAS
Repository Service API.
